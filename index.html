Audio Canvas

Generative art from music

How It Works

Audio is analyzed in real-time using the Web Audio API. Frequency data, amplitude, and beat detection feed into generative algorithms that create visuals unique to each song.

The Color Formula

color = f(pitch, tempo, amplitude)
  • Pitch → Hue (bass=red/orange, mids=yellow/green, highs=blue/purple/magenta)
  • Tempo → Saturation + hue shift (fast=vibrant/electric, slow=muted/earthy)
  • Amplitude → Brightness (quiet=dark, loud=bright)

Each song produces a unique chromatic fingerprint based on its harmonic and rhythmic content.

Blast Mode

When enabled, detects high beat rates (>8 beats/sec) like blast beats in metal. Instead of pulsing on every beat (which would be overwhelming), switches to sustained intensity for smooth flowing visuals.

Controls

  • Drop audio file or click to browse
  • Mic - Record from microphone
  • Tab - Capture audio from browser tab (YouTube, Spotify)
  • PNG - Export 4K raster image
  • SVG - Export vector for supported modes
  • Clear - Reset canvas
  • Mode buttons - Switch visualization (clears canvas)
  • +/-/0 - Zoom in/out/reset (keyboard shortcuts)
  • Drag - Pan around the canvas
  • Double-click - Reset zoom and pan

SVG Export

Many modes support vector export for infinite resolution and pen plotting:

  • Stars - Circles and lines, great for laser cutting
  • Tree - Branch paths, perfect for nature prints
  • Plotter - Single continuous stroke for AxiDraw
  • Spiro - Mathematical curves
  • Voronoi - Cellular tessellation
  • Mycelium - Organic branching networks
  • Contours - Topographic lines
  • Glass - Delaunay mosaic
  • City - Isometric architecture
  • Cymatics - Standing wave patterns

SVGs can be opened in Illustrator, scaled to any size, or sent directly to pen plotters.

ASCII Mode

Switches from canvas to text-based visualization. The entire screen becomes a grid of characters that respond to audio:

  • Character density represents amplitude
  • Wave patterns flow based on bass/mid/high frequencies
  • Colors map to pitch like the canvas modes

Lyrics Mode

Uses speech recognition to interpret vocals - even when it can't understand them. The neural network's confused attempts at transcribing screams/growls become visual data:

  • Misheard "words" rain down through the ASCII display
  • Character codes determine colors
  • Confidence scores affect opacity
  • Works best with ASCII mode enabled

The interpretation doesn't need to be correct - garbage text from black metal vocals creates abstract character patterns.

Tips

  • Let a full song play to build up dense, detailed artwork
  • Try different genres - each creates distinct visual signatures
  • Export during interesting moments or at the end
  • The same song will produce similar (but not identical) results each time
  • Enable ASCII + Lyrics together for text-based vocal visualization
